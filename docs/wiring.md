# Монтажная схема первого стенда

Эта схема рассчитана на одну KST X10, датчик Matek ASPD-4525, OLED 0,96″ I²C и Arduino Nano-совместимую плату ATmega328P. Перед пайкой **отсоединить USB**. Использовать базовый тест сервы `1500 → 1400 → 1600 → 1500 мкс`.

## Расположение выводов Nano

Плата ориентирована micro‑USB вверх, как на фотографии.

```text
Левая сторона:                         Правая сторона:
A7  5V  RST  GND  VIN                  D12 D11 D10 D9 D8 D7 D6 D5 D4 D3 D2 GND
```

## Схема соединений

```text
                         USB-зарядка / power bank 5 V
                                      │
                                      └── micro-USB Nano

┌──────────────── Arduino Nano ────────────────┐
│                                                │
│  5V  ────────┬── OLED VCC                      │
│              ├── ASPD-4525 5V                  │
│              └── KST X10: КРАСНЫЙ (+) *        │
│                                                │
│  GND ───────┬── OLED GND                        │
│             ├── ASPD-4525 G                     │
│             ├── KST X10: КОРИЧНЕВЫЙ (−) *       │
│             └── одна сторона каждой кнопки      │
│                                                │
│  A4  ───────┬── OLED SDA                         │
│             └── ASPD-4525 SDA                   │
│  A5  ───────┬── OLED SCL                         │
│             └── ASPD-4525 SCL                   │
│                                                │
│  D9  ────────── KST X10: ОРАНЖЕВЫЙ (сигнал)     │
│  D2  ────────── другая сторона кнопки «Вверх»   │
│  D3  ────────── другая сторона кнопки «Вниз»    │
│  D4  ────────── другая сторона кнопки «OK»      │
│  D5  ────────── другая сторона кнопки «Назад»   │
└────────────────────────────────────────────────┘

* Только временный стенд с одной сервой и базовым диапазоном.
```

## Цвета проводов

| Узел | Цвет провода | Что это | Куда паять |
| --- | --- | --- | --- |
| KST X10 | **красный** | питание `+` | `5V` Nano |
| KST X10 | **коричневый** | питание `−` / земля | `GND` Nano |
| KST X10 | **оранжевый** | PWM-сигнал | `D9` Nano |
| ASPD-4525 | красный* | `5V` | `5V` Nano |
| ASPD-4525 | жёлтый* | `SCL` | `A5` Nano |
| ASPD-4525 | синий* | `SDA` | `A4` Nano |
| ASPD-4525 | чёрный* | `GND` | `GND` Nano |

\* Цвета приведены для показанного на фотографиях четырёхжильного кабеля Matek. Если используется другой кабель или разъём был перепаян, ориентироваться только по надписям `5V/SCL/SDA/G` на плате датчика и по порядку контактов, а не по цвету.

У OLED и кнопок цвета проводов не стандартизированы: ориентироваться только по маркировке контактов (`GND/VCC/SCL/SDA`) на OLED и по назначению кнопки в таблице ниже.

## Питание сервы: ограничение первого стенда

Красный и коричневый провод KST X10 можно временно припаять к большим отверстиям `5V` и `GND` Nano. Питать Nano в этом случае только от **USB-зарядки или power bank 5 В**, не от USB-порта компьютера. Не подключать больше одной сервы и не использовать расширенный диапазон `1200–1800 мкс` до проверки механики и питания.

Если Nano перезагружается, OLED гаснет, появляются помехи на экране либо USB-источник отключается, немедленно отключить питание сервы. Для постоянной версии красный и коричневый провод сервы должны идти отдельной ветвью прямо от того же источника 5 В, минуя плату Nano; `GND` этой ветви остаётся соединённым с `GND` Nano.

## Проверка перед включением

1. Мультиметром проверить отсутствие короткого замыкания между `5V` и `GND`.
2. Подать питание без подключённой сервы: OLED должен включиться.
3. I²C-сканер должен обнаружить ASPD-4525 по `0x28` и OLED по `0x3C` или `0x3D`.
4. Подключить серву без тяги или при свободном ходе механики.
5. Запустить только базовый тест и наблюдать питание/экран.
