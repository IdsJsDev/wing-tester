# Быстрый тест Matek ASPD-4525

Для первой проверки без кнопок и сервы используется скетч [`firmware/aspd_4525_test/aspd_4525_test.ino`](../firmware/aspd_4525_test/aspd_4525_test.ino).

## Подключение

OLED и ASPD-4525 подключаются параллельно к одной I²C-шине Nano:

| Nano | OLED | ASPD-4525 |
| --- | --- | --- |
| `5V` | `VCC` | `5V` |
| `GND` | `GND` | `G` |
| `A4` | `SDA` | `SDA` |
| `A5` | `SCL` | `SCL` |

Кнопки, сервопривод и LoRa для этого теста не подключаются.

Скетч принудительно использует 100 кГц для обеих I²C-плат. Не устанавливайте для этой проверки 400 кГц: на общей самодельной проводке это может приводить к пропускам пакетов или зависанию шины.

## Загрузка и ожидаемый результат

1. В Arduino IDE установить библиотеку **U8g2**.
2. Открыть скетч `firmware/aspd_4525_test/aspd_4525_test.ino`.
3. Выбрать плату `Arduino Nano`, процессор `ATmega328P`; если загрузка не начинается — `ATmega328P (Old Bootloader)`.
4. Загрузить скетч, открыть Serial Monitor на `115200` бод.

Скетч использует постраничный буфер OLED, поэтому подходит для Nano с 2 КБ SRAM. Если IDE показывает почти полностью занятую динамическую память, убедиться, что открыт именно этот обновлённый скетч, а не сохранённая копия с конструктором дисплея, оканчивающимся на `_F_HW_I2C`.

Верхняя строка OLED показывает все адреса, найденные **при запуске** на I²C, например `I2C: 28 3C`. Ожидаются `28` (ASPD‑4525) и `3C` либо `3D` (OLED). Полный результат I²C-сканирования также выводится в Serial Monitor. Вторая строка показывает состояние ASPD‑4525 по адресу `0x28`.

- При включении выполняется калибровка нуля: 10 корректных измерений усредняются в течение примерно полусекунды. В это время OLED показывает `Калибровка` — не дуть в трубки и не закрывать их. После калибровки скорость в неподвижном воздухе будет близка к нулю.
- OLED показывает крупное русское значение `Скорость` в м/с, `Сбои` — число отдельных событий пропадания/некорректности данных, и `Ошибки` — суммарное число плохих пакетов. Несколько подряд плохих пакетов считаются одним событием `Сбои`.
- Сырые значения `RAW`, давление и температура остаются в Serial Monitor для отладки, но на OLED не выводятся.
- Кратко подуйте в трубку полного давления: значение `dP` и скорость должны измениться.
- Если связь пропала, OLED покажет `ASPD 0x28: LOST`. Нижняя строка `RX:n Err:a/b` показывает число принятых байтов (`n`, в норме `4`), ошибок подряд (`a`) и общее число ошибок (`b`). После возвращения датчика скетч автоматически найдёт его, выведет обновлённый I²C-скан и заново выполнит калибровку нуля.
- Сообщение `Data invalid` означает, что датчик ответил, но вернул неактуальные данные (`ST 2`) или собственную диагностическую ошибку (`ST 3`).

Показание скорости около нуля в спокойном воздухе может немного колебаться — это нормально для дифференциального датчика вблизи нулевого давления. До окончания `ZERO` значения `dP` и `Air` не являются результатом теста.
